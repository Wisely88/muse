# Muse-Director & AI 视频工业级生产中枢 (Video Studio 2.0)

专为 **Google Veo**、**阿里 Wan 2.1**、**快手可灵 (Kling)**、**MiniMax 海螺**、**Runway Gen-3/4**、**Sora**、**腾讯混元 (HunyuanVideo)** 打造的工业级 AI 视频导演与提示词编译中枢系统。

---

## 🌟 核心特色与架构升级 (v2.0)

### 1. 🎬 AI 主题一键导演工作站 (One-Click Topic Director)
- **只给一句话故事主题**，由 Gemini 认知大脑自动拆解为严格遵循好莱坞戏剧起承转合的 **3~6 幕连续分镜台账**；
- 锁定全剧主角外貌（Character Bible）与环境基调锚点，彻底杜绝换镜头“变脸”与背景断层；
- 每一幕卡片均提供 **【📥 载入至工坊精修】**，可无缝回填到主工作台进行手术刀级的参数与词库微调。

### 2. 🛡️ 严格双轨制纯英文编译 (Dual-Track Zero Chinese Leak)
- **中文视听轨 (Zh Track)**：专供人类创作者阅读，包括镜头景别、视听动态、机位运动与剧情说明；
- **纯英文指令轨 (En Track)**：专供海外与国产顶级视频大模型消费，100% 采用好莱坞电影导演级摄影英文术语，强制过滤任何中文字符与全角标点，杜绝中英文混杂。

  - 💎 **奢华商业广告微距 (Luxury Commercial)**：RED 8K 通透高反差、1000fps 超慢动作、轻柔磁性低语旁白

### 4. 🔌 统一多模型渲染网关 (Unified Model Gateway)
- 标准化模型抽象适配器接口 (`BaseVideoAdapter`)，实现多引擎热插拔与统一任务调度；
- 已内置预置适配器：
  - `Google Veo` (Gemini Video Hub 官方模型接口)
  - `阿里 Wan 2.1` (ComfyUI 本地私有化算力，无变形真人高保真)
  - `快手可灵 Kling` (商业短剧 API 调度)
  - `MiniMax 海螺 / Runway Gen-3` (大情绪张力与电影调色)
  - `MockLocalAdapter` (本地零成本仿真验证)

### 5. 🎞️ FFmpeg 全自动拼剪与音画合成器
- 支持读取分镜清单，自动执行 1080P 60fps 交叉叠化转场 (Crossfade Dissolve)；
- 自动混入环境声效（风沙、机械嗡鸣、BGM），一键导出成品短片。

## 🚀 启动与使用方式

### 方式 1：双击直接打开前端（免安装、零依赖）
直接在访达中双击打开 `index.html`，可在任何现代浏览器中离线运行前端提示词工坊与分镜编排。

### 方式 2：启动中枢服务网关 (推荐)
在当前目录运行：
```bash
python3 server.py
```
- 服务会自动监听 `http://localhost:8080`；
- 兼具前端静态工作台访问与后端 REST API 网关功能（支持 `/api/providers`, `/api/director/script`, `/api/render/submit`, `/api/render/assemble`）；
- 点击弹窗中的 **【🚀 调度引擎批量渲染全片】** 即可联动后端流水线。

## 🛠️ 技术栈与架构设计
- **前端核心**：纯原生 Vanilla JavaScript + Modern CSS (无任何 npm/webpack 外部重依赖，毫秒级冷启动)
- **调度网关**：Python 3 原生 HTTP Gateway + 适配器模式 (Adapter Pattern)
- **视频与声学合成**：FFmpeg (Complex Filtergraph + xfade + audio mixing)
- **多模态核心**：Google Gemini 认知大脑 (分镜架构与视频审片质检)
