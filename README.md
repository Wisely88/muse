# Muse & AI 视频专业提示词工坊 (Video Prompt Studio)

专为 **Meta Muse Video**、**腾讯 MuseV**、**Sora**、**Runway Gen-3**、**Luma**、**可灵 (Kling)** 以及配合 **Gemini / ChatGPT** 打造的专业视频提示词（Prompt）结构化生成工具。

---

## 🌟 核心特色

1. **黄金结构公式驱动**：
   $$\text{[主体]} + \text{[环境/场景]} + \text{[动作与动态]} + \text{[运镜/构图]} + \text{[风格/画质]} + \text{[光影/氛围]} + \text{[音效(可选)]}$$
2. **多风格一键切换**：
   - 🎬 **电影级大片 (35mm Film)**：好莱坞院线质感、变型镜头光斑、Arri Alexa 色调
   - 📱 **生活真实街拍 (POV/Vlog)**：iPhone 15 Pro 实拍质感、自然微晃、真实无修色
   - 💎 **高端商业广告 (Commercial)**：RED 8K、摄影棚通透柔光、极致细节与微距慢动作
   - 🌆 **赛博科幻未来 (Cyberpunk)**：双色霓虹夜雨、全息投影倒影、Blade Runner 质感
   - 🌿 **自然纪录片 (BBC Earth)**：超长焦微距、生动自然采光、60fps 流畅细节
   - 👤 **虚拟数字人 (MuseV 口播)**：主播正视镜头、自然微表情与口型同步
3. **三大模型导出模式**：
   - **自然语言流 (Cinematic Mode)**：自动拼装并翻译为纯正的好莱坞电影导演级英文长提示词，适用于 Meta Muse、Sora、Runway、Luma、Kling。
   - **标签权重流 (SD / MuseV Mode)**：自动生成 `(masterpiece:1.2), 1girl...` 标签式提示词，并配套生成防畸变负向提示词 (Negative Prompt) 与 YAML 任务配置。
   - **大模型扩写 (Gemini / GPT Mode)**：一键生成给大模型的专属指令，帮你分镜扩写更多运镜方案。
4. **内置灵感库与快捷标签**：
   - 顶部提供一键预设（科幻雨夜独行、咖啡馆生活Vlog、奢华香水大片、雪峰穿越机、虚拟人口播）。
   - 包含丰富的快捷词气泡（Chips），点击即可快速追加词汇。
   - 支持时序分镜（0-3s 起幅 / 3-6s 镜头推进演变）。

---

## 🚀 启动与使用方式

### 方式 1：双击直接打开（免安装、零依赖）
直接在访达中双击打开 `index.html`，或用 Chrome / Edge / Safari 浏览器打开即可。

### 方式 2：使用 Python 快速启动本地服务
在当前目录终端运行：
```bash
python3 server.py
```
终端会自动打开浏览器并访问 `http://localhost:8080`。

---

## 💡 使用小贴士

- **喂给视频大模型时**：优先复制**英文提示词**（大部分海外视频模型的语义理解对英文影视术语最精准）。
- **如果是生活化效果**：选择 **“生活真实街拍 (POV/Vlog)”**，工具会自动注入 iPhone 手持微晃感、自然无调色与生活细节词汇。
- **如果是电影级质感**：选择 **“电影级大片 (35mm)”**，工具会自动补充变形宽银幕、阿莱电影机色调与丁达尔光线。
